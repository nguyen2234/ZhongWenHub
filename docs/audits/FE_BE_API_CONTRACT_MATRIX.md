## TỔNG KẾT & KHOẢNG TRỐNG KIỂM THỬ (TEST GAP)

1. **Khối đã có Test Suite Backend + Frontend hoàn chỉnh (`REAL_WORKING`):**
   * Auth & Identity: JWT, Login, Register, Session restore, Profile (`AuthIntegrationTests.cs`, `auth-registration-and-onboarding.test.ts`).
   * Content Management: HSK Vocabularies, Characters, Courses, Units, Lessons, Grammar Points, Question Bank, Exams (`ContentController`, `QuestionBankIntegrationTests.cs`, `ExamServiceTests.cs`, `LessonReleaseGateIntegrationTests.cs`).
   * AI Learning Engine: AI Tutor (`GeminiProvider`), AI Conversations, AI Speaking (`GeminiSpeechRecognitionService`), Adaptive Exercises, Diagnostic Assessment, Competency Profile (`AILearningEngineIntegrationTests.cs`, `AITutorIntegrationTests.cs`).
   * Student Learning State: Sync XP, Streak, Lesson Progress, SRS Reviews (`LearningIntegrationTests.cs`).
   * Teacher Class Management: Dashboard KPIs, Class CRUD, Member enroll/remove, Class schedules (`TeacherClassServiceTests.cs`, `teacher-class-management.test.ts`).
   * Admin Users: CRUD, Lock/Unlock, Role Assignment, Reset Password, Wallet & Subscription Adjustments (`AdminUsersIntegrationTests.cs`, `user-management-redesign-and-isolation.test.ts`).

2. **Khoảng trống nghiêm trọng nhất (Major Test Gaps & Blocker P1):**
   * **Teacher Assignments:** Hoàn toàn thiếu Entity và Controller trên Backend. `assignment.service.ts` và `TeacherAssignmentsPage.tsx` không có bất kỳ integration test nào với SQL Server thật.
   * **Student Homework Runner & Attempts:** Hoàn toàn thiếu Entity và Controller trên Backend. Điểm số, thời gian làm bài, chống nộp trùng và bảo mật đáp án chưa có server-side validation.
   * **Video Fail-closed Handling:** Thiếu bài test xác minh khi API `/videos/{id}` trả về 500 hoặc rớt mạng thì UI phải bật Error State thay vì fallback sang `DEMO_VIDEOS`.
