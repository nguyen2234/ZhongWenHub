## TỔNG KẾT & KHOẢNG TRỐNG KIỂM THỬ (TEST GAP)

1. **Khối `RUNTIME_VERIFIED` (31 routes - 44.3%):**
   * Đã được bao phủ bởi các bài test tự động chạy trực tiếp trong test runner (`bun test` và `dotnet test`).
   * Không có giả lập bừa bãi hay nuốt lỗi contract.
2. **Khối `API_WIRED` (6 routes - 8.6%):**
   * Đã kết nối endpoint thật nhưng các bài test tích hợp live SQL Server và Playwright E2E đang bị skip theo điều kiện trong GitHub Actions CI workflow. Cần bổ sung test suite cô lập riêng trước khi tuyên bố 100% E2E.
3. **Khối `PARTIAL` (4 routes - 5.7%):**
   * `TeacherClassDetailPage`: Thiếu bài tập và bảng điểm thật.
   * `AdminRolesPage`: Thiếu endpoint lưu danh sách quyền cho vai trò vào DB.
   * `ContentManagerDashboardPage`: Thống kê đọc từ mock.
   * `GrammarPage`: Còn fallback tĩnh khi rớt mạng.
4. **Khối `MOCK_ONLY` & `BROKEN` (26 routes - 37.1%):**
   * **P1 Blocker:** Teacher Assignments (`assignment.service.ts`), Student Homework Runner & Attempt (`student-attempt.service.ts`), Student Classes (`StudentClassesPage.tsx`).
   * **P1 Blocker:** Video Learning (`video-learning.service.ts`, `VideoDetailPage.tsx`).
