## I. TỔNG QUAN HỆ THỐNG NGỮ PHÁP HSK 3

- **Tổng số điểm ngữ pháp**: 96 điểm.
- **Phạm vi mã hóa**: `GR30-HSK3-149` đến `GR30-HSK3-244`.
- **Phân bổ theo bài học**:
  - Bài 1 đến Bài 16: 5 điểm ngữ pháp / bài ($16 \times 5 = 80$).
  - Bài 17 đến Bài 20: 4 điểm ngữ pháp / bài ($4 \times 4 = 16$).
  - Tổng số bài bao phủ: 20/20 bài học.

## II. MA TRẬN PHÂN BỔ TRỌNG TÂM NGỮ PHÁP THEO BÀI HỌC

| Bài học | Chủ đề bài học | Điểm ngữ pháp trọng tâm | Cấu trúc công thức chính |
| :---: | :--- | :--- | :--- |
| **L01** | 周末你有什么打算 | Tiền tố 老-, Phó từ 大概/必须/几乎, Bổ ngữ 得/不 | `老—`, `动词+得/不+补语`, `主+谓+宾+谓+补` |
| **L02** | 他什么时候回来 | Hậu tố -家/-子/-员, Bổ ngữ 得很, Câu phức 先…再… | `—家、—子、—员`, `形容词+得很`, `先……，再/然后……` |
| **L03** | 桌子上放着一杯咖啡 | Phương vị từ, Phó từ 不用, Bổ ngữ 极了, Câu tồn hiện | `东、南、西、北、中间`, `放着+数量+名`, `或者……或者……` |
| **L04** | 她总是笑着跟客人说话 | Trợ từ 着 chỉ trạng thái động tác, Phó từ 总是 | `动词+着+动词`, `总是+动词` |
| **L05** | 我最近越来越胖了 | Cấu trúc biến đổi trạng thái tăng tiến 越来越 | `越来越+形容词/动词`, `越……越……` |
| **L06** | 怎么突然找不到了 | Bổ ngữ khả năng phủ định 找不到, Phó từ 突然 | `动词+不+到`, `怎么+动词` |
| **L07** | 我跟你一起去 | Giới từ 跟 kết hợp phó từ 一起 | `A+跟+B+一起+动词` |
| **L08** | 你去哪儿我就去哪儿 | Đại từ nghi vấn phiếm chỉ hô ứng | `疑问词……就……疑问词` |
| **L09** | 她的汉语说得跟中国人一样好 | So sánh bằng 跟…一样 kết hợp bổ ngữ trạng thái | `A+跟+B+一样+形容词`, `动词+得+补语` |
| **L10** | 数学比历史难多了 | So sánh hơn với 比 kết hợp bổ ngữ的多/得多 | `A+比+B+形容词+多了/得多`, `不但……而且……` |
| **L11** | 别忘了把空调关了 | Câu chữ 把 biểu thị sự xử lý tân ngữ và kết quả | `主语+别忘了+把+宾语+动词+结果` |
| **L12** | 把重要的事写在本子上 | Câu chữ 把 kết hợp bổ ngữ nơi chốn 在/到 | `主语+把+宾语+写/放+在+处所` |
| **L13** | 走得越快越好 | Cấu trúc tỷ lệ thuận 越 A 越 B | `越+形容词/动词+越+形容词/动词` |
| **L14** | 请把护照拿出来 | Câu chữ 把 kết hợp bổ ngữ xu hướng kép | `请+把+宾语+拿/带+出来/进去` |
| **L15** | 除了看书，他还喜欢运动 | Cấu trúc bổ sung / loại trừ 除了…以外 | `除了+A+以外，还/也+B`, `除了+A+都+B` |
| **L16** | 我现在累得不想动 | Bổ ngữ trạng thái / mức độ với trợ từ 得 | `动词/形容词+得+从句` |
| **L17** | 谁都有生病的时候 | Đại từ nghi vấn chỉ toàn bộ: 谁都… | `谁都+动词`, `如果……就……` |
| **L18** | 我相信你一定能做好 | Khẳng định niềm tin với 相信 và 一定 | `相信+宾语从句`, `一定+能+动词` |
| **L19** | 你没看懂这篇文章吗 | Bổ ngữ kết quả: 懂 / 看懂 / 听懂 và câu phản vấn | `没+动词+懂+吗`, `动词+懂` |
| **L20** | 只要努力就会有收获 | Cấu trúc điều kiện giả thiết 只要…就… và câu chữ 被 | `只要……就……`, `只有……才……`, `被+动词` |
