## 2. KIỂM ĐỊNH CẤU TRÚC VÀ CÔNG THỨC NGỮ PHÁP CỐT LÕI

### 2.1. Cấu trúc câu so sánh hơn với chữ 比 (Bài 11 & 12)
- **Công thức khẳng định:** `A + 比 + B + Tính từ`  
  - Ví dụ: `他比我大。` (Anh ấy lớn hơn tôi.)
- **So sánh có mức độ chênh lệch cụ thể:** `A + 比 + B + Tính từ + Độ chênh lệch`  
  - Ví dụ: `他比我大三岁。` (Anh ấy lớn hơn tôi ba tuổi.)
- **So sánh chênh lệch nhiều/ít:** `A + 比 + B + Tính từ + 得多 / 一点儿`  
  - Ví dụ: `北京的冬天比上海冷得多。` (Mùa đông Bắc Kinh lạnh hơn Thượng Hải nhiều.)
- **Phủ định:** `A + 没有 + B + (那么/这么) + Tính từ`  
  - Ví dụ: `这个问题没有你想的这么难。`

### 2.2. Trợ từ động thái 着 và 过 (Bài 13 & 14)
- **Trợ từ 着 (Biểu thị trạng thái đang tiếp diễn):**  
  - Công thức tồn hiện: `Nơi chốn + Động từ + 着 + Danh từ`  
  - Ví dụ: `门开着呢。` (Cửa đang mở đấy.) / `墙上挂着一张中国地图。` (Trên tường đang treo một tấm bản đồ.)
  - Công thức phương thức: `Động từ 1 + 着 + Động từ 2`  
  - Ví dụ: `老师笑着对我说。` (Thầy giáo cười nói với tôi.)
- **Trợ từ 过 (Biểu thị kinh nghiệm từng trải qua):**  
  - Khẳng định: `Chủ ngữ + Động từ + 过 + (Tân ngữ)` $\rightarrow$ `我去过北京。`
  - Phủ định: `Chủ ngữ + 没(有) + Động từ + 过 + (Tân ngữ)` $\rightarrow$ `我没去过中国。`
  - Nghi vấn: `... + 过...没有 / 吗？` $\rightarrow$ `你看过那个电影没有？`

### 2.3. Bổ ngữ trạng thái với 得 (Bài 12 & 14)
- **Công thức:** `Động từ + 得 + Tính từ / Cụm miêu tả`  
  - Ví dụ: `他跑得很快。` (Cậu ấy chạy rất nhanh.) / `你穿得太少了。` (Bạn mặc ít quá.)
- **Động từ mang tân ngữ:** `Động từ + Tân ngữ + Động từ + 得 + Bổ ngữ` (hoặc `Tân ngữ + Động từ + 得 + Bổ ngữ`)  
  - Ví dụ: `他汉语说得最好。`

### 2.4. Bổ ngữ kết quả (Bài 4, 6, 9)
- **Các bổ ngữ kết quả thông dụng HSK 2:** `完` (xong), `懂` (hiểu), `见` (thấy), `好` (sẵn sàng/tốt).
- **Ví dụ:**  
  - `做完` (làm xong): `题太多，我没做完。`
  - `听懂` (nghe hiểu): `老师讲的话，我都听懂了。`
  - `看见` (nhìn thấy): `你在路上看见小王了吗？`
  - `准备好` (chuẩn bị xong): `你准备好考试了吗？`
